# Graduate-Statistics-Teaching-Assistant-Resources
Teaching assistant resources for Quantitative Methods in Psychology I and II

This repository contains R code scripts for psychology graduate school statistics courses. The courses cover two semesters of quantitative methods in psychology. The courses are split into two folders, one for each semester. The first semester covers z and t-tests and analysis of variance. The second semester covers regression. The data used for these courses are not provided as they are the intellectual property of the course instructor. 

Each script includes student learning objectives for the class and the code provided to students to teach them how to perform statistical analyses in R.
